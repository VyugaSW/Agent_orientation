# Scrolling SOM: Living Membrane Navigation

Алгоритм локальной навигации автономного агента в двумерных стационарных и динамических средах на основе **тороидальных топологий, самоорганизующихся карт Кохонена**, **вычислительной топологии** и **эволюционных стратегий $(1+\lambda)\text{-ES}$**.

Вокруг агента формируется деформируемая сенсорная сеть с топологией на торе двух типов: квадратная сетка или сетка из шестиугольников. Мембрана упруго обтекает препятствия, локально искривляет метрику пространства и перемещается вместе с агентом за линейное время $\mathcal{O}(N)$ без перестроения графа связей.

## 1. Ключевые особенности архитектуры

- **Центральный тороидальный радар за $\mathcal{O}(N)$:** При движении агента узлы мембраны, отставшие за заднюю границу обзора, телепортируются на передний фронт вместе со своими решётчатыми якорями (`scroll_forward`), сохраняя топологические связи без перевыделения памяти.
- **Дискретное искажение метрики:** Препятствия (`DangerEntity`), аттракторы (`AttractorEntity`) и собственный след памяти агента изменяют локальные коэффициенты страха $k\_{\text{fear}}$ и желания $k\_{\text{desire}}$ каждого нейрона, превращая поиск кратчайшего пути в выбор нейрона-победителя (BMU) в искривлённой метрике.
- **Устойчивость к локальным минимумам (U-Traps):** Сочетание скользящего детектора циклов, испаряющегося репеллентного следа (Tabu / Pheromone Trail) и касательного обхода с топологическим анализом данных помогает выходить из глубоких П-образных ловушек.
- **Топологический анализ данных (TDA):** Размер ячейки и охват мембраны аналитически вычисляются из баркодов персистентных гомологий ($H\_0$ — ширина узких проходов, $H\_1$ — масштаб вогнутых полостей) фильтрации комплекса Чеха, а целостность самой сетки отслеживается в реальном времени через симплициальные числа Бетти ($\beta\_0, \beta\_1$).

## 2. Математическая модель класса `Agent`

Класс `Agent` (`Agent.py`) — это стандартный контроллер, который на каждом шаге выполняет один цикл: рассчитывает нужный вектор движения, выбирает лучший узел сетки (BMU) и делает шаг.

Пусть в момент времени $t$ агент находится в точке $\mathbf{x}\_{t} \in \mathbb{R}^{2}$, а цель — в $\mathbf{x}\_{\text{target}}$. Единичный вектор направления на цель:

$$\hat{\mathbf{d}}\_{\text{base}} = \frac{\mathbf{x}\_{\text{target}} - \mathbf{x}\_{t}}{\Vert{}\mathbf{x}\_{\text{target}} - \mathbf{x}\_{t}\Vert{}_2}$$

Горизонт планирования $L_{\text{look}}$ зависит от размера ячейки сетки $s$. При подходе к цели мы плавно отключаем обходные маневры с помощью коэффициента $\delta_{\text{turn}} = \min(1.0, D_{\text{goal}} / L_{\text{look}})$.

---

### 2.1. Уклонение от препятствий (векторный расчёт)

Для каждого ближайшего препятствия мы предсказываем, где оно окажется через 6 тиков (используя его вектор скорости $\mathbf{v}\_{k}$):

$$\hat{\mathbf{c}}\_{k} = \mathbf{c}\_{k} + 6 \mathbf{v}\_{k}$$

Если дистанция $d_k = {\|\mathbf{x}\_{t} - \hat{\mathbf{c}}\_{k}\|}_{2}$ меньше радиуса реагирования ${R}\_{\text{react}, k}$, мы строим вектор отталкивания и два ортогональных ему касательных вектора $\mathbf{t}_L$ и $\mathbf{t}_R$ (просто поворачивая нормаль на $\pm 90^\circ$).

Чтобы решить, обходить препятствие слева или справа, мы берём скалярное произведение касательных с базовым курсом $\hat{\mathbf{d}}_{\text{base}}$. Куда вектор смотрит лучше (где скалярное произведение больше), туда и поворачиваем. Выбранный касательный вектор $\mathbf{t}_k^*$ прибавляется к итоговому курсу пропорционально тому, насколько близко препятствие:

$$\mathbf{u}\_{\text{obs}} = \sum_{{d}\_{k} < R_{\text{react}, k}} \left(1 - \frac{{d}\_{k}}{R_{\text{react}, k}}\right) {F}\_{\text{tan}} \cdot {\delta}\_{\text{turn}} \cdot \mathbf{t}\_{k}^*$$

---

### 2.2. Защита от зацикливания и память траектории

Чтобы агент не бегал бесконечно внутри П-образного тупика, мы храним два списка:

1. **История позиций (окно $W_{h} = 40$ шагов):** Мы считаем отношение фактического перемещения от начала окна к идеальной длине пути. Если оно меньше $0.28$, значит, агент топчется на месте, и мы поднимаем флаг `is_in_loop = True`.
2. **Шлейф памяти (до 90 точек):** Агент оставляет за собой маркеры $\mathbf{b}\_{m}$ с весом ${S}\_{m}$. На каждом шаге вес старых маркеров убывает по экспоненте (${S}\_{m} \leftarrow 0.985 \cdot {S}\_{m}$).

Этот шлейф работает как искусственное препятствие. Во-первых, он даёт вектор отталкивания $\mathbf{u}\_{\text{mem}}$, который добавляется к курсу. Во-вторых, он локально штрафует узлы мембраны: если узел $n_i$ находится рядом со старым маркером, его коэффициент ${k}\_{\text{fear}}$ растет. В итоге тупик закрашивается большими весами, и алгоритм сам начинает искать выход наружу.

---

### 2.3. Ограничение угла поворота (сглаживание курса)

Суммарный вектор руления нормируется:

$$\hat{\mathbf{u}} = \frac{\hat{\mathbf{d}}_{\text{base}} + \mathbf{u}_{\text{obs}} + \mathbf{u}_{\text{mem}}}{\Vert{}\hat{\mathbf{d}}_{\text{base}} + \mathbf{u}_{\text{obs}} + \mathbf{u}_{\text{mem}}\Vert{}_2}$$

Чтобы агент не дергался, угол между старым вектором курса и новым не должен превышать $\theta_{\max} = 0.08$ радиан. Угол находим через скалярное произведение. Если он больше предела, мы жестко обрезаем его, умножая старый вектор на стандартную 2D-матрицу поворота:

$$\hat{\mathbf{u}}_{\text{new}} = \begin{pmatrix} \cos(\pm \theta_{\max}) & -\sin(\pm \theta_{\max}) \\ \sin(\pm \theta_{\max}) & \cos(\pm \theta_{\max}) \end{pmatrix} \hat{\mathbf{u}}_{\text{old}}$$

Знак поворота берётся из псевдоскалярного (косого) произведения векторов.

---

### 2.4. Выбор узла (BMU) и движение

Сначала фильтруем узлы мембраны: берём только те, что лежат в передней полуплоскости по ходу движения (проверка через скалярное произведение $> 0$).
Целевая точка $\mathbf{s}_{t}$ (стимул) проецируется вперёд по курсу $\hat{\mathbf{u}}$. На отфильтрованных узлах ищем минимум взвешенного расстояния:

$$n_{\text{BMU}} = \arg\min_{n_i} \left( \Vert{}\mathbf{p}_i - \mathbf{s}_t\Vert{}_2 \cdot k_{\text{fear}, i} \cdot k_{\text{desire}, i} \right)$$

Агент делает шаг $\Delta s$ в направлении найденного узла $\mathbf{p}_{\text{BMU}}$. Если после шага мы оказались внутри круга препятствия, просто сдвигаем координату по нормали к границе круга наружу.

## 3. Динамика ориентирующей мембраны (`Orientation_membrane`)

Мембрана — это просто неориентированный граф на торе (верхний край соединён с нижним, левый — с правым).

- **Адаптация Кохонена:** Мы запускаем обычный поиск в ширину (BFS) от узла-победителя $n_{\text{BMU}}$ на заданную глубину (например, до 4 связей). Чтобы не тянуть узлы через противоположный край тора, мы игнорируем рёбра, физическая длина которых больше $1.5s$. Найденные узлы сдвигаются к стимулу $\mathbf{s}_{t}$ с гауссовым весом (чем дальше по графу, тем слабее сдвиг).

- **Скроллинг:** Если координата узла выходит за пределы окна вокруг агента, мы просто прибавляем или вычитаем из неё период сетки $W$ или $H$. Граф при этом перестраивать не нужно, соседи остаются теми же.

- **Упругость (Гомеостаз):** У каждого узла есть своя "идеальная" позиция в сетке (якорь $\mathbf{a}\_{i}$). На каждом тике мы применяем аналог закона Гука — стягиваем текущую координату $\mathbf{p}\_{i}$ к якорю $\mathbf{a}\_{i}$ с коэффициентом ${\lambda}\_{\text{relax}}$. Это не даёт сетке смяться в точку.

- **Метрики связности (числа Бетти):** Мы берём безопасный подграф (узлы с $k_{\text{fear}} \le 2$).
  - $\beta_{0}$ — это количество компонент связности (считается одним проходом BFS).
  - $\beta_{1}$ — это количество циклов. Так как мы знаем число вершин $\vert{}V\vert{}$,рёбер $\vert{}E\vert{}$ и $\beta_{0}$, циклы тривиально находятся по формуле $\vert{}V\vert{} + \vert{}E\vert{} = \beta_{0} - \beta_{1}$

## 4. Вычислительная топология и адаптация формы (`TopologyOptimizer`)

Модуль `TopologyOptimizer.py` предоставляет два способа автоматической настройки геометрии мембраны (`ParameterizedMorphologyTopology`: масштабы $s\_x, s\_y$, кривизна фронта $\kappa$, "направление взгляда" $\gamma$):

1. **Аналитический конфигуратор через персистентные гомологии (клавиша `H`):**
   Строит матрицу поверхностных зазоров фильтрации Чеха $G\_{ij} = \|\mathbf{c}\_i - \mathbf{c}\_j\|\_2 - (r\_i + r\_j)$ на препятствиях карты, где ${c}\_{i}$ - центр $i$-го препятствия, ${r}\_{i}$ - его радиус.
   - Из спектра положительных зазоров между различными связными компонентами препятствий ($H\_0$) определяется ширина минимального прохода $\delta\_{H\_0}$, задающая шаг сетки $s$.
   - Из двумерного размаха слившихся кластеров стен ($H\_1$) оценивается масштаб вогнутых ловушек $R\_{H\_1}$, определяющий размерность сетки $R \times C$.
2. **Эволюционная стратегия $(1+\lambda)\text{-ES}$ (клавиша `E`):**
   Оптимизирует 7-мерный вектор генома $\mathbf{g} = (s\_x, s\_y, \kappa, \gamma, F\_{\text{tan}}, \eta, \lambda\_{\text{relax}})^T$ в серии быстрых безэкранных симуляций, минимизируя штраф за время достижения цели, терминальную невязку, столкновения и осцилляции курса.

## 5. Структура проекта

```text
--Agent.py                  # Класс агента: кинематика, касательные, Tabu-память и цикл step()
--Orientation_membrane.py   # Тороидальная SOM-мембрана: поиск BMU, BFS-адаптация, гомеостаз, числа Бетти
--Topology.py               # Стратегии решёток (Square, Hexagonal) и декоратор ParameterizedMorphologyTopology
--Neuron.py                 # Модель узла мембраны и расчёт искажённой метрики расстояний
--InfluenceEntity.py        # Статические, движущиеся и пульсирующие объекты среды (DangerEntity, AttractorEntity)
--Environment.py            # Пространственное хеширование (SpatialHashEnvironment) и CostmapEnvironment
--TopologyOptimizer.py      # Анализ карты через персистентные гомологии (H_0, H_1) и эволюционный алгоритм
--Visualizer.py             # Графический движок на Pygame с кэшированием поверхностей и HUD-телеметрией
--main.py                   # Генераторы 5 уровней, точка входа в приложение и набор Unit-тестов
```

## 6. Установка и запуск проекта

### Требования

- **Python** 3.9 или выше
- Библиотеки: `numpy`, `pygame`

### Установка зависимостей

```bash
pip install numpy pygame
```

### Запуск интерактивной визуализации

```bash
python main.py
```

### Запуск модульных тестов (Unit Tests)

В файле `main.py` содержится полный набор модульных тестов (`unittest`), проверяющих искажение метрики нейронов, тороидальные связи, отсутствие отскока после телепортации, правило ножниц, динамические объекты и гомологический анализатор:

```bash
python -m unittest main.py -v
```

## 7. Управление в симуляторе

| Клавиша / Действие          | Описание                                                                                                           |
| :-------------------------- | :----------------------------------------------------------------------------------------------------------------- |
| **`ЛКМ` (Левый клик мыши)** | Установить новую глобальную цель (`target`) в любой точке арены                                                    |
| **`1`**                     | **Уровень 1 (Stripe):** Сплошная вертикальная преграда поперёк прямого пути                                        |
| **`2`**                     | **Уровень 2 (U-Trap):** Глубокая П-образная ловушка для проверки выхода из локального минимума                     |
| **`3`**                     | **Уровень 3 (Forest):** Плотная группа препятствий с узкими зазорами                                               |
| **`4`**                     | **Уровень 4 (Obstacle Field):** Асимметричное поле крупных препятствий                                             |
| **`5`**                     | **Уровень 5 (Dynamic Swarm):** Динамическая среда с патрулирующими и исчезающими препятствиями                     |
| **`H`**                     | Мгновенно перестроить размер и форму мембраны через **персистентные гомологии ($H_{0}, H_{1}$)** карты             |
| **`E`**                     | Запустить **эволюционный оптимизатор $(1+\lambda)\text{-ES}$** для поиска оптимальной морфологии на текущем уровне |
